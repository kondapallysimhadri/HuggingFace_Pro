# 🏡 House Price Prediction (California Housing)

This is a small **Machine Learning project** that predicts house prices in California using the **California Housing dataset** from scikit-learn.

## 🚀 Features
- Built-in dataset (`fetch_california_housing`)
- **Random Forest Regressor** for price prediction
- **Streamlit App** for interactive inputs
- **EDA Notebook** for dataset analysis

```bash
python train_model.py
